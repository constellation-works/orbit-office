# Screens

One module per screen lands here:

- `today` — Needs you, Agents working on, Done today, drop zone.
- `chat` — the orchestrator; pastes are visibly saved as sources.
- `source` — original beside anchorable text, with citing tasks and pages.
- `todos` — You and Agents columns, each with source and attached knowledge.
- `routines` — plain-sentence cards with on/off, last run, retention.
- `library` — About / How-to / Outputs, citations, refs, back-links, history.
- `insights` — automation ratio, metric tiles, "what got automated".
- `review` — generated reviews with citations, and regenerate.
