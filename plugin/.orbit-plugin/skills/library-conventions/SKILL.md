# Library conventions (scaffold)

Stub skill. The full conventions land with the knowledge slice:

- Sources are evidence: captured once, never edited; corrections are new versions.
- Knowledge is derived: every claim cites a source anchor (`src-…#t=…`, `#L…`).
- Artifacts are outputs: produced as task artifacts, promoted into the Library
  only on approval, versioned by series, never edited in place.
- Never store secrets in a knowledge page; pointers (`refs`) name files,
  links, contacts and templates only.
